# 0.1.0纯辅助模块候选

本发行提供两个独立APK，按需要安装，不必同时安装。Phigros对应com.PigeonGames.Phigros、参考4.0.1（157）；Phira对应org.flos.phira、参考0.8.2（39）。模块包名为org.rhythmlab.assist.phigros与org.rhythmlab.assist.phira，均code1。参考版本表示Activity入口已核对，不代表已经在这些手机版本验收。

桌面打开模块可使用皮肤资源工作台。游戏内辅助需要root/LSPosed：启用模块、仅勾选对应原版游戏，强行停止游戏再启动，长按音量上键打开辅助面板。首次使用显示说明与免责声明。普通按键仍交给原窗口；识别到长按之前系统音量可能已经改变。关闭面板请点击“收起”。

当前实现：窗口亮度、前台常亮、手动Android界面回调间隔采样；ZIP皮肤只读检查、图片预览、音效试听、元数据查看、原字节副本导出与删除。采样不是游戏FPS，也不分析谱面。窗口状态在Activity暂停时恢复。皮肤检查副本存于本模块内部，不读取游戏存档；导出目标由你在系统文件选择器指定。

皮肤工作台只接受图片/音效/元数据ZIP，拒绝代码、未知文件、不安全路径、CRC损坏及超额解压。最多64MB压缩包、128MB展开总量、32MB单文件、1024条目、64KB文本。最多保留20份检查副本，达到容量上限须自行删除。PNG基础尺寸检查不等于完整渲染。

**Phira继续通过原版资源包功能手动导入；Phigros的游戏内换肤尚未接入。** 本版不会将预览标成已应用，不接受“改后缀就跨游戏通用”的说法。Malody只提供制作流程参考，不构建Malody模块。特效/音效/线色适配路线见仓库文档。

不提供自动游玩、自动输入、判定、分数、准确率、误差、RKS、历史、解锁或货币修改。没有原生库、旧实验模块类、游戏引擎或原素材，不声明网络/存储全盘/系统悬浮窗权限；原游戏自己的网络行为不受阻断。源码和DEX能力核对已通过。

**没有连接或操作手机，本次未确认真实LSPosed挂接、Android界面、导出或皮肤效果。** 构建与主机测试不等于手机成功，先按候选使用。保留原始资源，不要公开私钥、凭据、私人存档或设备日志。免责声明在模块首页、实际辅助入口和发行附件中提供；不构成免责保证。
