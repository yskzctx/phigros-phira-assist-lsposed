# 0.2.0 · 游玩实时 HUD 候选

两款APK只提供辅助，没有自动游玩、判定或成绩修改。Malody是显示思路参考，不是适配游戏。

## 安装与开启

1. 按需安装Phigros辅助或Phira辅助；包名与0.1.0相同，可覆盖更新辅助模块。它们不替换原版游戏。
2. LSPosed启用模块，只勾选对应游戏：Phigros为`com.PigeonGames.Phigros`，Phira为`org.flos.phira`。请勿同时启用旧实验控制模块。
3. 冷启动原版游戏，长按音量上键打开浅色辅助设置，阅读免责声明。
4. 开启“游玩 HUD · 漏击 / 击中 / ACC 曲线”；可选四角位置、大小和底板不透明度，收起设置后游玩。HUD不接收触摸，无需系统悬浮窗权限。
5. 切出游戏会移除HUD并恢复窗口亮度/常亮。设置在对应游戏内的辅助SharedPreferences中保留；统计曲线只存于内存。重新启动后若之前启用HUD，须阅读本次进程免责声明后才显示。

## 数据含义

- 漏击：Miss数；击中：Perfect＋Good；Bad独立列出。
- ACC：`(P + 0.65 × Good) / (P + Good + Bad + Miss) × 100%`，属于已判定音符的累计准确率。无判定显示“—”，不显示虚假的100%。
- 曲线横轴为已判定音符数，纵轴有区间标注。真实变化才新增点，显示压缩保留分桶极值与首尾，不补造接入前曲线。
- Phigros从原版更新后的现有计数读取；Phira旁观原版判定事件，原参数原样转交。Phira中途接入只统计接入后片段，会明确标注。超过1.5秒未更新会提示保留末次统计。
- 这不是按整谱总音符计算的完成度，也不是目标ACC、游戏结算分数或官方成绩证明。暂停时没有判定不会产生新曲线点。

## 适配和未完成验收

只支持已核对ELF的arm64-v8a Phigros4.0.1（157）与Phira0.8.2（39）。完整SHA-256、函数前缀见`native/profiles.json`；同版本的不同ELF不强行适配。先验证版本、架构与文件哈希，再验证可执行段和函数前缀；未匹配不接入HUD，不影响基础辅助。LSPosed还必须提供Native Hook接口；未就绪时显示具体状态，不冒充已连接。

已做主机统计/解码/曲线限额/原调用转交与只读数据测试，以及编译、签名、16KB对齐、DEX/ELF导出与权限核对。**尚未连接手机，未确认真实LSPosed加载、游玩计数一致、重开/换谱、Android触摸穿透与性能。请按候选验收，不能当作已实测正式版。**

建议真机对照：手动游玩一局产生P/G/Bad/Miss，比较HUD与结算；重试并换谱确认重置；分别切后台/返回、关HUD、切四角，确认游戏触摸不被拦截。不需要改任何原版存档。

皮肤工作台沿用0.1功能：ZIP检查、图片/音效预览、元数据及原字节导出；Phira通过原生功能导入，Phigros游戏内换肤仍未接入。
