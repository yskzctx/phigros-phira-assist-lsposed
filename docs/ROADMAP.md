# 后续范围

本仓库只接受使用辅助与视觉资源相关功能。当前交付包括两个Java辅助入口、独立只读原生HUD观察器和资源检查工作台，不是完整的跨游戏皮肤引擎。

1. 优先验收真实游玩HUD：逐项对照P/G/Bad/Miss与结算、换谱/重试重置、暂停/后台停止、触摸穿透与性能；中途接入不得伪造前段历史。再确认两游戏真实设备上加载、长按入口、窗口状态恢复、图片/音效预览及文件导出。
2. Phira：按其原生资源规范补充更完整的特效、音效和线色诊断，避免重复原版皮肤选择器。
3. Phigros：单独核对显示资源入口，再开发只影响可见资源的适配。必须有停用恢复与资源生命周期验证，不能借显示适配夹带游玩修改。
4. 可继续增加无判定干预的显示可读性、皮肤制作检查和本地诊断；每项说明实际实现、设备验证和限制。

禁止引入自动触摸、自动游玩、判定/时序/分数/准确率/误差操控、RKS/记录/解锁/货币编辑、网络结果伪造或校验绕过。新功能不得打包旧实验控制库或游戏资源。源码能力检查与APK检查必须随版本执行。
